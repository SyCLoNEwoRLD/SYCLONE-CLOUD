# Security

Please report security problems **privately**: on this repository's GitHub page, open
**Security → Report a vulnerability**. Do not open a public issue for them.

Include what you found, how to reproduce it, and which release you used (`combind --version` on
the Mac). You will get an answer as soon as possible; please give time for a fix before telling
others.

Only the latest release receives security fixes. To update, see
[docs/operations.md](docs/operations.md).
